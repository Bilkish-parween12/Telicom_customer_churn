Telecom Customer Churn Analysis 📊

Project Overview

This project focuses on analyzing customer churn in a telecom company using Python.
The goal is to understand customer behavior, identify churn patterns, and explore the factors that may influence customers to leave the company.

Objectives

- Analyze customer churn distribution.
- Understand churn patterns based on gender and senior citizen status.
- Explore the relationship between tenure and customer churn.
- Analyze churn across different contract types.
- Examine phone, internet, and additional service usage.
- Compare payment methods and their relationship with churn.

Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Data Cleaning

- Inspected dataset structure and column names.
- Checked missing values and duplicate customer IDs.
- Converted "TotalCharges" into a numeric data type.
- Handled blank values in "TotalCharges".
- Converted the "SeniorCitizen" column into readable Yes/No values.

Exploratory Data Analysis (EDA)

- Visualized overall customer churn using count plots and pie charts.
- Compared churn across gender and senior citizen groups.
- Analyzed customer tenure and churn patterns.
- Explored contract types and their relationship with churn.
- Created multiple subplots to analyze phone and internet-related services.
- Examined payment methods and calculated overall and contract-wise churn rates.

Key Insights

- Month-to-month contract customers have the highest churn rate (42.71%).
- Two-year contract customers have the lowest churn rate (2.83%).
- Customer tenure is an important factor to explore when understanding churn behavior.
- Service usage and payment methods provide additional insights into customer churn patterns.

Conclusion

This project helped me practice data cleaning, exploratory data analysis, data visualization, and extracting meaningful insights from telecom customer data.
The analysis can help identify customer groups that may need better retention strategies.
